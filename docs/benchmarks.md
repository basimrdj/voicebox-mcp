# VoiceBox Objective Benchmarks & Evaluation Protocol

## 1. Benchmarking Philosophy

In accordance with the VoiceBox Breakthrough Directive:
- **Zero Fabricated Studies**: We do not publish simulated or hypothetical human listener counts as completed empirical facts.
- **Reproducible Evaluation Suite**: All reported metrics are generated by deterministic, automated test suites and reproducible ASR pipelines executable locally via `bun test tests/evaluation_suite.test.ts`.
- **Confidence Intervals**: All perceptual and statistical measures are accompanied by Wilson score intervals or Student's $t$ confidence bounds ($\alpha = 0.05$).

---

## 2. Test Environment & Hardware Specifications

All baseline benchmarks are measured under the following standardized conditions:
- **Platform**: Apple Silicon M-Series (macOS Darwin 25.1.0) / Ubuntu 24.04 LTS (x86_64, CUDA 12.4).
- **Runtime**: Bun v1.3.10 / Python 3.10.11 / PyTorch 2.4.
- **Audio Output**: 24,000 Hz / 48,000 Hz, 16-bit linear PCM.
- **Test Utterance**: Standard 7-word benchmark sentence: *"I am completely fine with this decision."*

## 4. Open Double-Blind Perceptual Evaluation Protocol

Rather than asserting unverified past human studies, VoiceBox ships with a fully automated, reproducible double-blind listening test framework:
- **Harness**: `src/evaluation/blind_study_framework.ts` and `demo/index.html`.
- **Methodology**:
  1. Presents randomized, level-normalized, anonymized audio pairs to listeners.
  2. Evaluates two independent dimensions:
     - **Intended Communicative Intent Recognition**: 8-way forced choice.
     - **Perceptual Naturalness (MOS)**: 1–5 Likert scale.
  3. Computes Wilson 95% confidence intervals and confusion matrices.
  4. Stores raw trial logs in JSON format for open scientific scrutiny.
